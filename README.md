# SkyCast Weather Dashboard

SkyCast is a simple weather dashboard that lets you search any city, use your current location, and compare current conditions with a 5-day forecast.

## Features

- City search with optional country code
- Current location lookup using browser geolocation
- Celsius/Fahrenheit toggle
- Recent search history
- Responsive layout for desktop and mobile
- Weather-aware themes and richer forecast cards

## Setup

1. Get a free API key from OpenWeatherMap.
2. Copy `config.example.js` to `config.js`.
3. Paste your API key into `config.js`.
4. Open `index.html` in a browser or run the project with a local server.

## Usage

- Type a city name and click Search.
- Add a country code like `US`, `PH`, or `GB` if needed.
- Click Use my location to load weather for your current area.
- Use the unit toggle to switch between metric and imperial.
